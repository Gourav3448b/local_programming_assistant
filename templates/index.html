ABOUT THE PROJECT

How CodeMentor works

This project trains a compact GPT-style Transformer from random initialization using PyTorch. It combines the trained model with a small local programming Q&A retriever.

01 / TrainMiniGPT learns next-byte prediction from the included dataset.
02 / RetrieveA local TF-IDF search finds relevant programming examples.
03 / RespondThe app selects a relevant reference or displays the local model's draft.

No external model API is called. The model is intentionally small, so its free-form generations are experimental.
