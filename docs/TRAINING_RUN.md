# Included checkpoint: training record

The packaged `artifacts/minigpt.pt` was generated by running the included trainer from random initialization with:

```bash
python -m local_llm.train --steps 800 --log-every 200 --output artifacts/minigpt.pt
```

Configuration:

- Training examples: 74 total (68 training records and 6 held-out validation records)
- Trainable parameters: 124,800
- Byte/special-token vocabulary: 258
- Context window: 128 bytes
- Embedding width: 64
- Attention heads: 4
- Transformer blocks: 2
- Batch size: 8
- Optimizer: AdamW
- Learning rate: 0.0003
- Device used for this run: CPU

The validation records are kept separate at the Q&A-example level, so their question-answer pairs are not included in training windows. The validation estimate samples random windows from those six held-out examples.

These values show that the model learned patterns in its small training stream. They do **not** prove that it can answer unseen programming questions correctly. The raw generation quality remains experimental; the local retriever provides the stronger answers for topics covered by the included examples.
